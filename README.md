# Lab Practicals - Artificial Intelligence

This repository contains Python implementations for Artificial Intelligence laboratory practicals.

## Index of Practicals

- **Practical 1 (`practical_1.py`)**: Design and implement a Simple Reflex Agent for the Vacuum Cleaner World and analyze its rational behavior.
- **Practical 2 (`practical_2.py`)**: A* search algorithm for solving the 8-puzzle problem using heuristic search (misplaced tiles).
- **Practical 3 (`practical_3.py`)**: Tower of Hanoi puzzle solved using State-Space Search (Breadth-First Search).
- **Practical 4 (`practical_4.py`)**: Local Beam Search applied to the Travelling Salesman Problem (TSP) with 2-opt transitions.
- **Practical 5 (`practical_5.py`)**: Breadth-First Search (BFS) for solving the 8-puzzle planning problem.
- **Practical 6 (`practical_6.py`)**: Depth-First Search (DFS) for solving the Water Jug Problem (4L and 3L jugs).
- **Practical 7 (`practical_7.py`)**: Backtracking Search to solve the 8-Queens Constraint Satisfaction Problem (CSP).
- **Practical 8 (`practical_8.py`)**: Simple rule-based chatbot using pattern matching and keyword detection.

## How to Run

Run any practical script using Python:

```bash
python practical_1.py
python practical_2.py
python practical_3.py
python practical_4.py
python practical_5.py
python practical_6.py
python practical_7.py
python practical_8.py
```
